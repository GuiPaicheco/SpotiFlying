# Contribuir

Use Python 3.12 x64 em Windows. Instale `requirements-lock.txt` em uma venv. Execute `python -m ruff check src tests packaging` e `python -m pytest`. Inicie a demo com `python packaging/launcher.py --demo`.

Use faixas, LRC e arte fictícios nos testes e evidências. Ao mudar o comportamento de sobreposição, anote SO, escala, modo e o aplicativo que recebeu o clique. Registre as funcionalidades que dependem de uma sessão Spotify real.
