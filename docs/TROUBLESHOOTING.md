# Solução de problemas

| Sintoma | Como diagnosticar |
| --- | --- |
| O Spotify não aparece | Use o Spotify Desktop e inicie uma faixa. Reinicie a reprodução se o Windows tiver retomado de suspensão. Teste a demo para verificar a interface. |
| Letra faltando | Vincule um arquivo UTF-8 em Letras ou habilite a busca LRCLIB. Se houver várias versões, escolha a que corresponde ao álbum e à duração. |
| Letra fora do tempo | Um offset positivo adianta a letra. Ajuste em etapas de 50 ms e verifique se a sessão expõe posição. |
| Cartão fora da tela | Use Posicionamento → Centralizar overlays ou restaure Stories. |
| Atalho recusado | Use uma combinação livre ou deixe o campo vazio para desativá-la. |
| Cartão sem resposta | Ative interação pela bandeja ou com Ctrl+Alt+I. A capacidade de seek e outros comandos depende da sessão. |
| Overlay some no jogo | Tente o modo janela sem bordas se ele estiver disponível. Desktop seguro, DRM e anti-cheat podem limitar janelas externas. |
| Dados portáteis em outro local | Veja a pasta efetiva em Sobre. Sem permissão de escrita ao lado do executável, o app utiliza LocalAppData. |

Exporte o diagnóstico pela bandeja ou em **Privacidade**. O relatório contém versão, SO, escala, fonte e disponibilidade da sessão, sem títulos, letras ou caminhos pessoais.
