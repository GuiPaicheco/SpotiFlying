Aplicativo para Windows x64

Letras na tela, no ritmo da música.

Acompanhe as letras do que toca no Spotify Desktop e veja a faixa atual em um miniplayer, direto na área de trabalho.

Baixar para Windows Conhecer o app

Do seu jeito, sobre o desktop.

Use as duas sobreposições juntas ou escolha qual mostrar. Mude fonte, posição, tamanho e aparência pela central.

Letras sincronizadas

Vincule arquivos LRC ou ative a busca no LRCLIB. Ajuste a sincronia e escolha como as letras aparecem, com destaque por linha ou por palavra.

Miniplayer sob demanda

Veja a faixa atual no modo passivo, que deixa os cliques passarem para a janela abaixo. Use Ctrl + Alt + I para interagir com o cartão e Esc para voltar.

Experimente no Windows.

Abra o Spotify Desktop e toque uma faixa ou selecione Demo offline na central para experimentar com faixas fictícias. A busca online por letras é opcional.
